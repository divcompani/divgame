دیوولی — صعود جادوییراهنمای نسخهٔ ۳ و آپلود روی هاست

این بسته مستقل از chatgpt.site است. تصاویر، فونت فارسی و منطق تولید موسیقی و افکت‌های صوتی داخل فایل‌ها هستند. برای اجرای بازی، حساب Sites، کلید API، نصب Node.js یا پایگاه داده لازم نیست.

وضعیت این نسخه: بازی قابل اجراست؛ فرم ثبت‌نام، جوایز و کدها نمایشی‌اند. محدودیت یک جایزه در همین مرورگر ذخیره می‌شود و با پاک‌کردن داده‌ها یا استفاده از دستگاه دیگر قابل دورزدن است. این بسته برای توزیع جوایز واقعی یا جلوگیری قطعی از تقلب کافی نیست.

آپلود روی GitHub Pages

بله؛ این بازی از HTML، CSS و JavaScript ساخته شده و با GitHub Pages سازگار است. با پلن رایگان، مخزن عمومی بساز. فقط آپلودکردن فایل ZIP باعث اجرای سایت نمی‌شود؛ ابتدا فایل‌ها را از ZIP بیرون بیاور.

  1. در GitHub یک repository تازه، مثلاً divoolee-game، ایجاد کن.
  2. فایل Divoolee-v3-GitHub-Pack.zip را روی کامپیوتر Extract کن.
  3. داخل مخزن از Add file → Upload files محتویات استخراج‌شده را بارگذاری کن؛ خود ZIP را بارگذاری نکن. فایل index.html باید در ریشهٔ مخزن کنار فایل‌های JavaScript و پوشهٔ assets باشد. پوشهٔ assets را با همهٔ محتویاتش منتقل کن.
  4. دکمهٔ Commit changes را بزن.
  5. به Settings → Pages برو. در Source گزینهٔ Deploy from a branch را انتخاب کن. شاخهٔ main و پوشهٔ /(root) را انتخاب و Save کن.
  6. تا انتشار صبر کن؛ ممکن است تا حدود ۱۰ دقیقه طول بکشد. آدرس دقیق را از همان صفحهٔ Pages و دکمهٔ Visit site بردار. معمولاً شبیه https://USERNAME.github.io/divoolee-game/ است.

فایل خالی .nojekyll در بسته برای ارائهٔ مستقیم فایل‌های استاتیک آمده است. اگر فایل‌های مخفی هنگام آپلود دیده نمی‌شوند، می‌توانی آن را از Add file → Create new file با همین نام بسازی. مسیرهای فایل‌ها نسبی‌اند و هم برای ریشهٔ دامنه و هم برای زیرپوشهٔ مخزن آماده هستند.

منابع: تنظیم منبع انتشار GitHub Pages و ساخت سایت، فایل ورودی و زمان انتشار.

این بسته به chatgpt.site وابسته نیست. GitHub Pages فایل‌های بازی را ارائه می‌کند، اما ثبت‌نام واقعی یا کنترل جوایز سمت سرور را اضافه نمی‌کند. قوانین تک‌جایزه همچنان نمایشی و محدود به همان مرورگرند.

آپلود در cPanel

  1. در پنل هاست وارد File Manager شو.
  2. برای یک دامنهٔ اصلی معمولی، به public_html برو. اگر دامنه یا زیر‌دامنهٔ جدا داری، پوشهٔ Document Root همان دامنه را انتخاب کن.
  3. یک پوشهٔ تازه به نام divoolee بساز و وارد آن شو تا سایت فعلی‌ات جایگزین نشود.
  4. فایل Divoolee-v3-GitHub-Pack.zip را با Upload بارگذاری کن.
  5. فایل را انتخاب و Extract کن. فایل index.html باید مستقیماً در همان پوشه، کنار style.css و پوشهٔ assets باشد.
  6. آدرس https://YOUR-DOMAIN/divoolee/ را با دامنهٔ خودت باز کن. استفاده از HTTPS توصیه می‌شود و امکانات ذخیره‌سازی و قفل هم‌زمان در مرورگرها مطمئن‌تر خواهد بود.

مبنای مراحل بارگذاری و استخراج: راهنمای رسمی File Manager در cPanel. نام برخی گزینه‌ها ممکن است با ظاهر پنل هاست شما تفاوت داشته باشد.

اگر هاست دیگری داری

ZIP را روی کامپیوتر استخراج کن. همهٔ محتویات آن، شامل فایل index.html و پوشهٔ assets را با فایل‌منیجر یا SFTP داخل پوشهٔ مقصد دامنه بارگذاری کن. این نسخه فقط فایل‌های استاتیک دارد؛ تنظیم build یا پایگاه داده نمی‌خواهد. ساختار پوشه‌ها و نام فایل‌ها را حفظ کن.

اجرا روی کامپیوتر خودت

ZIP را استخراج کن. اگر Python 3 نصب است، در همان پوشه دستور python3 start-local.py را اجرا کن؛ در ویندوز می‌توانی py -3 start-local.py را بگذاری. مرورگر روی http://127.0.0.1:8790 باز می‌شود. تا وقتی بازی را می‌خواهی، پنجرهٔ اجرا باز بماند؛ برای توقف Ctrl+C بزن.

بازکردن مستقیم index.html ممکن است در بعضی مرورگرها برای صدا یا ذخیره‌سازی محدودیت داشته باشد؛ اجرای محلی بالا یا آپلود روی هاست روش مناسب‌تر است. آدرس 127.0.0.1 فقط روی همان دستگاه کار می‌کند.

بازی چطور کار می‌کند؟

  • پرش عمودی: با فرود روی هر سکو، پرش بعدی خودکار انجام می‌شود. روی کامپیوتر کلیدهای چپ/راست یا A و D برای هدایت‌اند. روی موبایل، دکمه‌های پایین یا کشیدن انگشت روی بازی برای هدایت هستند.
  • جهش کمکی: Space، فلش بالا یا دکمهٔ جهش. هر ۲٫۶ ثانیه دوباره شارژ می‌شود. برای فرار از گوی‌های آتش نگهش دار.
  • سه جان: سه شعلهٔ آبی بالای بازی دیده می‌شود. در دو آسیب اول، یک جان کم می‌شود و بازیکن با محافظت کوتاه به سکو برمی‌گردد. آسیب سوم، مسیر و امتیاز را صفر می‌کند. دور بعد با سه جان تازه شروع می‌شود.
  • سختی: هر ۱۸۰ امتیاز یک درجه بیشتر؛ سکوها باریک‌تر، زودتر متحرک و شکننده می‌شوند. سرعت شبیه‌سازی از حدود ۱ برابر شروع می‌شود و با امتیاز تا ۳٫۶ برابر بالا می‌رود. از امتیاز ۱۸۰، پایین صحنه بالا می‌آید. از ۹۰۰، گوی‌های آتش پس از ۰٫۸۵ ثانیه هشدار واقعی وارد می‌شوند؛ این هشدار در سرعت زیاد کوتاه نمی‌شود.
  • امتیاز: از ارتفاع جدید و شعله‌ها؛ ایستادن و تکرار یک ارتفاع امتیاز اضافه نمی‌دهد.
  • جادوها: سپر یک ضربه را می‌گیرد؛ آهن‌ربا ۸ ثانیه کار می‌کند؛ زمان آهسته ۶ ثانیه سرعت بازی را کم می‌کند.
  • صدا: بعد از لمس شروع فعال می‌شود. ♪ برای قطع همهٔ صداها و گزینهٔ موسیقی برای خاموش‌کردن موسیقی زمینه است. با مکث یا رفتن به پنجرهٔ دیگر موسیقی متوقف می‌شود. آهنگ و افکت‌ها در مرورگر تولید می‌شوند؛ فایل موسیقی نمایش‌های واقعی در بسته نیست.

قانون یک جایزه

جوایز فقط پس از تمام‌شدن هر سه جان نمایش داده می‌شوند. امتیاز و مسیر زنده صفر می‌شوند، اما نتیجهٔ دور تمام‌شده تا شروع دور بعد برای انتخاب جایزه نگه داشته می‌شود. بازیکن از بین جایزه‌هایی که در همان نتیجه به آن‌ها رسیده، فقط یکی را انتخاب و تأیید می‌کند. این انتخاب همهٔ جوایز دیگر کمپین را در همان مرورگر قفل می‌کند. رکورد قدیمی قابل استفاده نیست. شروع دور تازه یا تازه‌سازی صفحه، فرصت انتخاب نتیجهٔ ثبت‌نشده را از بین می‌برد.

گرافیک و امکانات توسعه

دیوولی چهار حالت تصویری با رندر سه‌بعدی از زاویهٔ پشت/کنار دارد؛ ترکیب نرم حالت‌ها، جمع و بازشدن بدن و حرکت نرم دوربین به پرش اضافه شده است. در صفحهٔ اول، لمس یا کلیک روی دیوولی نمای پشت را از میان ۸ زاویه به روبه‌رو می‌چرخاند و لمس بعدی آن را برمی‌گرداند. این چرخش نمایشی با تصاویر چندزاویه‌ای است، نه مدل سه‌بعدی آزاد. فایل turntable.js نمایش این بخش را کنترل می‌کند. شعله‌های رنگی، رد نور، درخشش و لایه‌های عمقیِ متحرک حس حجم می‌دهند. اجرای بازی ۲٫۵بعدی روی Canvas است؛ مدل سه‌بعدی قابل‌چرخش یا موتور WebGL در بسته وجود ندارد.

برای اسپانسرها می‌توان دروازهٔ اختصاصی برند، مأموریت هفتگی، آیتم جادویی و بستهٔ جایزهٔ مشترک افزود. برای عرضهٔ واقعی لازم است ورود با تأیید شماره، کنترل امتیاز سمت سرور، سقف موجودی هر جایزه، کدهای قابل‌اعتبارسنجی و محدودیت یکتای بازیکن/کمپین در پایگاه داده پیاده‌سازی شوند.

تغییر تنظیمات

در engine.js جدول REWARDS نام و امتیاز جوایز را دارد. آستانهٔ گوی‌های آتش ۹۰۰، افزایش مرحله ۱۸۰ و سقف سرعت ۳٫۶ نیز در همین فایل هستند. audio.js موسیقی و افکت‌ها، style.css ظاهر و game.js رابط فارسی/انگلیسی و نقاشی بازی را کنترل می‌کنند. قبل از تغییر از بسته یک کپی نگه دار.

رفع اشکال

  • هنوز chatgpt.site باز می‌شود؟ آن لینک نسخهٔ قبلی است؛ آدرس دامنهٔ خودت یا پیش‌نمایش محلی را باز کن.
  • صفحهٔ خالی یا تصویر خراب: پوشهٔ assets و همهٔ فایل‌های JS/CSS باید کنار index.html باشند؛ پس از جایگزینی فایل‌ها صفحه را تازه‌سازی کامل کن.
  • صدا نمی‌آید: ابتدا شروع را لمس کن، سپس ♪ و گزینهٔ موسیقی و صدای دستگاه را بررسی کن. مرورگر بدون تعامل کاربر صدا را شروع نمی‌کند.
  • دریافت جایزه غیرفعال است: باید هر سه جان تمام شده باشد، امتیاز نتیجهٔ همان دور کافی باشد و در همین مرورگر قبلاً جایزه انتخاب نشده باشد. ذخیره‌سازی مرورگر هم باید فعال باشد.
  • روی هاست خودت خطای 403 می‌بینی: پوشهٔ مقصد و دسترسی فایل‌ها را با پشتیبانی همان هاست بررسی کن. مشکل سرویس قبلی با انتقال این فایل‌های مستقل به هاست شما همراه نمی‌شود، اما دسترسی هاست جدید را خود آن سرویس کنترل می‌کند.

بررسی‌های انجام‌شده

۱۵ آزمون منطق بازی و جوایز گذرانده شده‌اند: ریست پس از سه آسیب، سپر و محافظت موقت، مکث و شارژ جهش، امتیاز ارتفاع، قابل‌رسیدن‌بودن سکوهای تولیدشده، برخورد در سرعت زیاد، هشدار آتش، سرعت افزایشی، جلوگیری از انتخاب جایزه پیش از باخت، نتیجهٔ پایان دور، قفل تک‌جایزه و خطای ذخیره‌سازی. اتصال رابط و دو زبان با محیط شبیه‌سازی‌شده بررسی شده‌اند. نمای روبه‌رو پس از لمس و نمایش جوایز پایان بازی در مرورگر مشاهده شده‌اند. کیفیت صدا و توازن سختی در همهٔ دستگاه‌ها ارزیابی نشده؛ قبل از کمپین واقعی، آن را روی دستگاه‌های هدف و با بازیکنان واقعی امتحان کنید.
